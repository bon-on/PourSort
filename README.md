# PourSort

A small color sort puzzle built with Flutter (web, iOS, Android). Pour colored
liquid between tubes until every tube holds a single color.

## How to play

- Tap (or click) a tube to select it, then tap another tube to pour.
- The top run of one color moves as far as the target has room. You can pour
  onto an empty tube or onto a tube whose top color matches.
- Each tube holds 4 segments. Win when every tube is empty or full of one color.
- Every color also has its own symbol, so the game is playable without
  telling hues apart.
- Buttons: Undo (unlimited), Restart, and add one extra empty tube per level.
- Stars: finish at or under par (the solver's move count) for 3 stars, a few
  moves over for 2, else 1. Using the extra tube caps a level at 2 stars.
- Level select (`L` or the grid button) replays any reached level with its
  stars. Clears earn XP; player levels unlock four themes (Lab, Potion Shop
  Lv3, Candy Lv6, Night Bar Lv10) in the theme picker (`P`).
- Keyboard: `1`-`9`, `0`, then `Q W E T Y I` select tubes (shown under each
  tube), `U` undo, `R` restart (replay after winning), `A` extra tube,
  `L` levels, `P` themes, `Enter`/`N`/`Esc` next level after winning. In the
  level and theme overlays: arrows move, `Enter` picks, `Esc` closes. Undo is disabled after a win; restarting a level restores its extra
  tube.
- First launch shows a skippable "How to play" card; the `?` button reopens
  it (Enter/Space next, Esc skip, arrows to move between steps).
- Sound effects (select, pour, invalid, level clear, cork, level up) and a
  bubbly background music loop, with one speaker button to mute both; the
  choice is saved locally. Music starts after the first input on web and
  pauses while the tab is hidden. CrazyGames builds also follow the portal
  mute setting.
- Levels start with 3 colors and grow to 10. Level N is always the same level,
  and every level is verified solvable. Progress (levels, stars, XP, theme) is
  saved locally under `pour_sort.progress_v1`; saves from older versions are
  migrated.

## Run, test, build

```sh
flutter pub get
flutter run -d chrome          # or any device
flutter analyze
flutter test
flutter build web --release --base-href /PourSort/
```

## CrazyGames build

`tool/build_crazygames.sh` builds `build/pour-sort-crazygames.zip` for the CrazyGames portal (SDK gameplay events, no ads). See `docs/crazygames.md`.

## GamePix build

`tool/build_gamepix.sh` builds `build/pour-sort-gamepix.zip` for GamePix (no portal SDK, no ads, relative resources). See `docs/gamepix.md`.

## Sounds

Generated by `tool/generate_sounds.py` (Python 3 standard library only, deterministic), no third-party audio. Run `python3 tool/generate_sounds.py` to regenerate `assets/audio/*.wav` (the music loop is 16 kHz mono, under 1 MB).

## Fonts

Roboto (Regular, Medium, Bold, Black) is bundled in `assets/fonts/` so web builds never fetch it from fonts.gstatic.com. Roboto is licensed under Apache 2.0, see `assets/fonts/Roboto_LICENSE.txt`.

## Project layout

- `lib/logic/` - rules, solver, level generator, stars, player progress and store (no widgets)
- `lib/art/` - code-drawn tubes, cork and themed sceneries
- `lib/audio/` - sound effects and music loop (web HTML audio, native channel) and the mute store
- `lib/ui/` - game screen, board painter and effect clock, HUD, overlays
- `test/` - unit tests and a widget smoke test
- `harness/` - specs, ADRs and contracts (spec-driven development)
